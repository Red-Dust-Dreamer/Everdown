## 上传步骤

1. 登录 [developer.taptap.cn](https://developer.taptap.cn) → 创建游戏 → 选 **小游戏 / H5** 形态。
2. 填游戏资料(文案见下节),上传图标与截图。
3. **游戏包管理 → 小游戏管理** → 上传 `abyss-idle-taptap-2.0.0.zip`,版本号填 `2.0.0`。
4. 回到资料页 **游戏下载** → 选中刚上传的包体(两步缺一不可,官方教程特别强调)。
5. 提交审核。无版号 → 以**测试**形式上架(开放下载没问题;本游戏无内购,天然合规)。
   审核若要求接入实名/防沉迷,再按 TapTap SDK 文档接入,不阻塞其他步骤。

## 版本号规则

后续更新:`package.json` 改大版本号 → `bash scripts/package-taptap.sh` 重新出包 →
上传的新版本号必须大于线上版本。脚本会自动用 package.json 的 version 命名 zip。

## 技术备注(开发者向)

- 打包脚本 `scripts/package-taptap.sh`:`VITE_BASE=./` 相对路径构建 →
  校验无根绝对路径 → python zipfile 组包(zip 内统一正斜杠)。
- `store-assets/demo-save.json` 由 `scripts/mk_demo_save.ts` 核心快进 3h 生成(Lv.46),
  供重截商店图用。注意:注入存档要在**同源静态页**(如 manifest.webmanifest)写
  localStorage 再导航进游戏——游戏 `pagehide` 会把旧档写回,直接在游戏页注入会被覆盖。
- 大陆玩家访问 Supabase(排行榜/云存档)可能不稳,游戏本体托管在 TapTap CDN 不受影响。
