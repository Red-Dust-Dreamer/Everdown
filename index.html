❔ 机制速查

核心循环

英雄自动战斗不停歇:推进模式击败敌人深入深渊,挂机模式停在指定层刷金币与装备。 掉落靠评分自动换装(新装备比当前强 5% 才换),你主要负责花金币变强、看掉落、推边界。

金币就是战力

挂机赚来的金币不会自动变强,要花出去:强化装备(战斗页装备框 → ⚒)、升级已装配技能(技能页)、 祭坛献祭(金币换永久加成,保留到转生之后)。卡墙推进变慢时,第一反应永远是"金币花了吗"。

卡墙了怎么办

连续战败会自动转挂机(这是保护,不是惩罚)。强化/技能/祭坛跟上后会自动恢复推进; 若等级到 50 且长期受阻,考虑转生(角色页)——带着永久加成重爬更快,还能换职业。

等级压制

怪物强度随区域与层级上涨,属性跟不上时伤害会越来越刮痧——这就是该回头强化/转生的信号, 不是 bug。

装备与锁定

背包里点 🔒 可锁定心爱的装备,锁定件不会被一键出售/批量分解。 分解比出售金币略高,史诗以上还出重铸石(洗练词缀用);一键按钮共用品质档选择。

重铸石与幸运

重铸石来自分解(史诗+)与头目掉落,在装备详情里洗练词缀;幸运提升高品质掉落率(有上限)。

每日循环

悬赏任务每日有完成上限、可刷新 3 次;深渊塔钥匙每日 3 把(0 点重置);药剂 30 分钟增益,价格翻倍递增。

存档安全

存档在浏览器本地,设置页可导出 JSON 备份;绑定云账号(设置页)后多设备漫游,换机不丢档。

⚒ 金币就是战力!

你已攒下 0 金币,却一次强化都没做过—— 推进变慢的根源往往在这:挂机赚来的金币不会自动变强,要花出去。

两条花钱主线:强化装备(战斗页装备框点开 → ⚒ 强化/⚒×10)、 升级技能(技能页,已装配的技能每级都实打实提战力)。卡墙时尤其该花。
